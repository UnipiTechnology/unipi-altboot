!!! ATTENTION !!!!
Booting this image invokes unconditional cleaning content of eMMC storage on your Unipi device.
The operating system, deployed Mervis solution and any other data WILL BE LOST.

Installation via USB flash drive:
USB flash must be formated with first primary partition type FAT32 (or exFAT with newer U-Boot versions),
free size has to be at least used space by main system + 200 MB.
You don't need to delete usb storage content. Just copy all files to root directory 
of USB flash. 

time   step
 -1s    1. Insert into USB, press and hold the SERVICE button
  0s    2. Power on the unit
  ..    3. Wait 10-15 seconds until all LEDs (excepted PWR) start flashing
 10s    4. Release the SERVICE button
        5. Wait up to two minutes for completion of the flashing procedure
125s    6. All LEDs will dim and the PLC is restarted
140s    7. Fresh system is running

For more information follow our tutorials on https://kb.unipi.technology
